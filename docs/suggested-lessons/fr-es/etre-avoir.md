# Être & Avoir

Base language: Spanish. Target: French. Présent tense. See the
[shared mechanics](../README.md#shared-mechanics).

## Content

Spanish → French subject pronouns:

| es | fr |
|---|---|
| yo | je |
| tú | tu |
| él | il |
| ella | elle |
| nosotros | nous |
| vosotros | vous |
| ellos | ils |
| ellas | elles |

French pronouns used for conjugation: `je tu il elle on nous vous ils elles`.

| pronoun | être | avoir |
|---|---|---|
| je | suis | ai |
| tu | es | as |
| il / elle / on | est | a |
| nous | sommes | avons |
| vous | êtes | avez |
| ils / elles | sont | ont |

## Lessons

| # | Title | Prompt → answer | Instruction (es) |
|---|---|---|---|
| 1 | Pronombres | Spanish pronoun → French pronoun (8 tasks) | Escribe el pronombre en francés que corresponde. |
| 2 | Être | French pronoun → form of être (9 tasks) | Escribe la forma correcta de être para este pronombre. |
| 3 | Avoir | French pronoun → form of avoir (9 tasks) | Escribe la forma correcta de avoir para este pronombre. |
| final | Être o avoir | French pronoun + requested verb tag → form (18 tasks) | Se indica el verbo pedido: escribe la forma correcta. |

Distractors for multiple choice come from the lesson's own answers (all French
pronouns; all être forms; all avoir forms; both verbs combined in the final).
