# Tutor

AI-assisted language-learning app (learner drives, AI teaches). Before working
here, read:

- `docs/architecture.md` — data model (profiles → items + evidence), conventions,
  localization rules (all UI strings in en/es/pl), product decisions.
- `docs/roadmap.md` — what's done and the next steps.
- `docs/suggested-lessons/` — archived content of the original hardcoded games.

Commits: do not add Claude/AI co-author or attribution lines.

This project uses [Convex](https://convex.dev) as its backend.

`convex/_generated/ai/guidelines.md` first** for important guidelines on
how to correctly use Convex APIs and patterns. The file contains rules that
override what you may have learned about Convex from training data.

`npx convex ai-files install`.
